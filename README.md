# Sample Mount Catalogue

A catalogue of epoxy grain mounts used for geological sample analysis.

Each mount has its own page with:

- mount details (preparation, polish, coatings, storage)
- the samples it contains and where each sits in the mount
- map images of the mount
- grain data and other files

Each physical mount has a QR code that links to its page.

**Browse the catalogue:** https://mnts.au

The site is built with GitHub Pages.
